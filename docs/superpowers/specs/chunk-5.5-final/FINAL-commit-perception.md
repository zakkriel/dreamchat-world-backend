# FINAL — Commit & Perception (SCAFFOLD — locked rulings + open questions)

**Founder goal this file serves:** NOTHING is forgotten. CONFIDENCE AT CHECKPOINT: ~70%.

## Locked
- Only the engine writes canon. Canon is append-only, replay-safe, never hard-deleted; repairs are
  compensating events/merges, never edits.
- Six event types are the only currency. Every write carries provenance to its licensed cause.
- The resolved outcome declares its **visible vs hidden** split; perceptions are generated from the
  visible aspect per receiver. Canon and perception diverge on purpose (she IS afraid and lies; you
  perceive confidence). No component lies — the world does.
- The recording of an unblocked action is clerk work (event row, position update, clock tick) — not a
  judgment.

## OPEN
1. Fan-out fidelity rules (who perceives what, with what degradation — distance, senses, language).
2. The perception payload composition for the narrator (and for NPC cognition — same wall?).
3. How hidden truths later surface (inference, discovery) without violating the wall.
4. Memory scoping over long horizons (nothing forgotten ≠ everything in every prompt — retrieval rules).

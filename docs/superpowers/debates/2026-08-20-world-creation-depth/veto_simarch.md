# Veto audit — simarch

No hard-veto breach: no social-structure identifier, no enum of kinds, no Tier-1 growth, no
`relationship_state` write, no gate enforcement, no DDL. AC-1 honours wire-or-delete. Three defects.

**1. AC-3's delivery claim is false, and cites the wrong function.**
PRD: *"Those holders are exactly what `fn_private_records` already feeds cognition
(`schema.sql:2734-2740`) — the law reaches minds with zero new read paths."*
`:2734-2740` is `fn_public_moment`; `fn_private_records` is `:2677-2725`. Three filters kill the
claim: (a) `:2714-2718` requires the perception's subjects to intersect the action's bound ids — a
norm's subjects do not; (b) `:2707` excludes any record whose source event is held with modal
content by **all** present holders — AC-3 fans identical rows citing one event, so a norm binding
the room is classified `shared` and dropped; (c) `privateRecords` runs only for NPCs flagged by
`fn_isolated_npcs`, and `buildBatchPrompt` passes `private = nil`
(`cognitionprompt.go:100-102,395-412`) — the default batch seat never renders it. It cannot reach
`fn_public_moment` either: `:2749` needs every present holder, and the player holds none. This is
the same "reaches no mind" failure §3 says it corrected.

**2. AC-3 inverts B-7.** PRD: *"One authored text, engine-made copies: B-7's no-drift rule
satisfied."* B-7 is not a no-drift rule — it forbids *"the copy-the-record implementation shortcut
that makes everyone a witness"* (`06_rules_register.md:32`), which is precisely identical rows on
one source event. The governing authority is B-2's common-knowledge clause (`:27`); cite that, or
AC-3 breaches the rule it invokes.

**3. AC-5 lacks the vacuity clause its siblings carry.** AC-3/4/10 state "vacuous when…"; AC-5's
test — *"Two briefs differing only in marked/concealed produce differing roster lines"* — is
unstatable for a tide, rota or taboo world with no collective.

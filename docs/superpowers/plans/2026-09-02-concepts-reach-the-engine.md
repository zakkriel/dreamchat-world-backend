# Concepts Reach The Engine — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop discarding the seven concepts a world authors, and give the model that writes the world's history their meaning instead of a list of names.

**Architecture:** Concepts become registered entities (`entity_kind='concept'`), and a concept's `descriptor` **is** its truth — so no new table and no engine ADR. The history weaver's scope carries name-plus-truth instead of bare names. Separately, a knowledge-visibility hole that would leak every faction's private position is closed before anything can rely on it.

**Tech Stack:** Go 1.26, PostgreSQL 17, `dbmate` migrations, pgTAP for engine invariants, `go test` for handler/commit paths.

## Global Constraints

- Design of record: `docs/design/2026-09-02-concepts-as-knowledge.md`. Future system: `SPEC-051`.
- **No new gate, belt, validation layer, or "knowledge subsystem."** Founder's constraint, verbatim: *"do not go creating crazy gates and crazy test and validations in the code and call them a system. we want it to keep it clean as (speed, velocity and the physics engine)."*
- **Nothing stores "is this wrong."** No wrongness flag anywhere, per the design's §4.
- **No numbers in prompts.** A grade, when it exists, renders as prose. This round has no grades.
- Concepts are registered on the documented `origin='fast_path'` genesis exception (**D-1**).
- The fill is **not changed** this round. `what_it_is` is used as authored.
- Migration discipline: `make migrate` and commit **both** `core/db/schema.sql` and `core/api/migrations.txt` (**ADR-P020**).
- Branch must contain `origin/main` (`branch-currency.yml`).
- PR body must carry `Areas:` / `Reviewed-by:` from `../harness/review.sh --pr-body`, and every cited id must resolve (`ci/check_citations.sh`).

## Scope correction, read before starting

The approved defaults included a positions/knowledge table that "starts empty and fills in play." Having checked the code: **nothing in play would write to it this round** — teaching is not implemented, and forks require an inference path that does not exist. Shipping an empty table with no writer is the "we changed the schema and nothing happened" failure this design was written to avoid.

So the knowledge table, the grade, and the roll are **deferred to the round that implements teaching**, and are already catalogued in `SPEC-051`. What ships here needs **zero DDL and zero engine ADR**, and still delivers the founder's actual ask: concepts reach the weaver.

**Factions are also not transcribed this round.** They cannot be: `belongs_to` is parsed into `genesisActor.BelongsTo` and never persisted, and no membership table exists anywhere in the schema. Registering factions without membership would make every faction's knowledge world-visible through the hole Task 1 closes. Faction transcription needs a membership decision of its own.

### Task 1 (original, void): Close the faction knowledge leak

**Interfaces:**

- Produces: `fn_visible_perceptions(p_world_id uuid, p_viewer_id uuid)` keeps its signature and `SETOF perception_record` return. Only the `WHERE` narrows.

- [ ] **Step 3: Write the migration**

Remove the unconditional faction/group branch. There is no membership representation to check against yet, so the honest narrowing is to the holder alone, with the reason recorded at the code.

```sql
-- migrate:up
CREATE OR REPLACE FUNCTION public.fn_visible_perceptions(p_world_id uuid, p_viewer_id uuid)
RETURNS SETOF public.perception_record
LANGUAGE sql STABLE
AS $$
  -- A perception is visible to its holder. The previous version also returned every
  -- perception held by ANY 'faction'/'group' entity to EVERY viewer, with no membership
  -- condition -- broadcast, not shared knowledge. It was inert only because genesis never
  -- registers a faction. Restored when membership exists; see
  -- docs/design/2026-09-02-concepts-as-knowledge.md §7 and SPEC-051 item 8.
  SELECT pr.*
  FROM perception_record pr
  WHERE pr.world_id = p_world_id
    AND pr.invalid_tick IS NULL
    AND pr.expired_at IS NULL
    AND pr.holder_id = p_viewer_id;
$$;
```

Expected: the new pgTAP assertion PASSES and every existing invariant (I-1…I-10) stays green.

```go
// conceptLines gives the weaver each idea AND what it is. conceptNames gave it the
// bare word, which is why authored history never referenced a concept: a model cannot
// weave a doctrine it knows nothing about. It receives the truth and no position --
// positions do not exist yet, and the weaver resolves the truth without speaking it
// (design 2026-09-02 §6).
func conceptLines(doc *genesisDoc) []string {
	out := make([]string, 0, len(doc.Concepts))
	for _, c := range doc.Concepts {
		name := strings.TrimSpace(c.CanonicalName)
		if name == "" {
			continue
		}
		if what := strings.TrimSpace(c.WhatItIs); what != "" {
			out = append(out, name+" — "+what)
			continue
		}
		out = append(out, name)
	}
	return out
}
```

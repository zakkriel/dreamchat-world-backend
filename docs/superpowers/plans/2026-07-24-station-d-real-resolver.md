# Station D — The Real Resolver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the resolver's fakes-and-fail-louds with the real thing: rich rulings (truth/appearance/per-receiver variants + attribute writes through the Tier-1 wall) committed via `apply_ruled_event`, a one-hop truth gather, N-ary combined rulings, and a real LLM driver — so "I lean on Mara and she can refuse" works end to end.

**Architecture:** The ruling contract moves to `ruling/2` (deception split per RULINGS-2026-07-24 §4, typed event slots per §6). SQL gains `gather_slice` (truth-side R1) and `apply_ruled_event` + `apply_attribute_writes` (R4 for ruled outcomes — canon records truth, perceptions render the face). Go gains the Tier-1 registry (the wall, enforced), verdict extensions (id-whitelist, tier checks), an N-ary adjudicate path with a cache-layout prompt, and a generic OpenAI-compatible driver. CI keeps fakes (no network); live tests skip without keys.

**Tech Stack:** Go (core/api, package main, module `dreamchat/core/api`), PostgreSQL via dbmate migrations + pgTAP tests (`make reset && make test`), JSON Schema draft-07, existing bridge/driver registry.

## Global Constraints

- **Scope fence:** the corpus (`docs/superpowers/specs/chunk-5.5-final/`, now incl. `RULINGS-2026-07-24-reaction-beat.md`). Not ruled → stop and ask.
- **Blocker-only; D-1 (only SQL writes canon); measurements-not-verdicts; six types only; append-only canon.** Unchanged and binding.
- **Canon never lies (RULINGS-2026-07-24 §4):** ruled event `truth` is what canon records; perceptions come from receiver variant → default appearance → truth; `visible=false` ⇒ no perceptions.
- **The Tier wall (§6):** tier-1 attribute writes strictly validated against the in-code closed set; tier-2 written as-is, never engine-read; a tier-2 write may NOT use a Tier-1 name.
- **SPEC-011 lesson (hard rule):** every new schema file carries `$id` (house form `name/N`) and non-projection schemas are registered in `INPUT_CONTRACT_SCHEMAS` in `ci/schema_contract.py`. `make schema-contract` is part of the battery.
- **Harness:** dbmate `-- migrate:up`/`-- migrate:down`; `schema.sql` regenerated by `make migrate` (never hand-edited); pgTAP house style (fixed uuids, fresh names, `plan(N)`/`finish()`/`ROLLBACK`); Go commands from `core/api/`.
- **CI has no network:** default bridge stays fakes; any live-LLM test skips unless its env key is set.
- **Battery per task:** `make reset && make test` · `cd core/api && go test -count=1 ./...` (re-run TestBeat/TestRunBeat for stability) · `make schema-check` · `make schema-contract`.
- **TDD failing-test-first; one commit per task minimum; plain comments with examples.**
